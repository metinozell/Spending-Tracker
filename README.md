# 💸 Spending-Tracker

A **simple and lightweight** personal expense tracking tool built with **Python**.
Easily record your daily expenses, view summaries, and analyze your spending habits over time.

---

## ✨ Features

✅ Log expenses with **date, category, description, and amount**
✅ Save data in a **JSON file (`expenses.json`)**
✅ View **total spending summaries**
✅ *(Planned)* Filter by **date range** or **category**
✅ *(Planned)* Generate **charts and visual reports**

## 🚀 Getting Started

### 🔧 Prerequisites

* Python **3.7+** installed
* (Optional) Virtual environment tool (venv, pipenv, etc.)

### 📥 Installation & Run

1. Clone this repository:

```bash
git clone https://github.com/metinozell/Spending-Tracker.git
cd Spending-Tracker
```

2. (Optional) Create a virtual environment:

```bash
python -m venv venv
# Windows
.\venv\Scripts\activate
# macOS / Linux
source venv/bin/activate
```

3. Run the app:

```bash
python main.py
```

---

## 💻 Usage Example

When you run `main.py`, you will be asked:

```
Enter expense amount:
Enter category:
Enter description:
Enter date (YYYY-MM-DD) or leave blank for today:
```

💾 All data is automatically saved in **`expenses.json`**.
